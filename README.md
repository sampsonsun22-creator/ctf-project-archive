# CTF 项目备份与知识库

项目索引和阅读说明在 [START_HERE.md](START_HERE.md)。五个周大福项目的背景、决策和跨系统依赖见 [共享工作记忆](knowledge/CTF_五项目共享工作记忆.md)。SBUX 是一套独立的参考案例。

原件按项目打包，发布后可在 [Releases](https://github.com/sampsonsun22-creator/ctf-project-archive/releases) 下载。ZIP 保留项目目录、原始文件名和原始字节，版本与校验结果随备份记录。

## 给获准使用此仓库的模型

先读 `START_HERE.md`，再按项目和问题查阅证据。区分已确认决策、讨论方案和待确认事项，注明来源路径和日期。仓库包含已保存的项目文件和工作记忆。ChatGPT 项目中未导出的聊天和内部记忆需要单独导出。
